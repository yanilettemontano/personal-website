# Personal Portfolio Website

My personal portfolio site which is built to showcase my research, projects, technical teams, and coursework as a Computer Engineering student at UC Irvine.

**Live site:** https://personal-website-delta-ten-53.vercel.app/

## About

A clean, single-page portfolio aimed at firmware, embedded systems, and hardware engineering roles. Projects and hands-on hardware work come first, followed by experience, skills, research, and relevant coursework.

## Tech Stack

- **React** + **Vite**
- **React Icons** for the GitHub, LinkedIn, and email icons
- Plain CSS with custom properties; dark mode follows the visitor's system setting

## Sections

- Projects
- Experience
- Skills
- Research & Publications
- Relevant Coursework
- Contact

## Running Locally

```bash
git clone https://github.com/yanilettemontano/personal-website.git
cd personal-website
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.

## Deployment

Deployed via Vercel with automatic redeploys on every push to `main`.
